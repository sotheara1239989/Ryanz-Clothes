Literature review

  • •
    Web Architecture: Traditional PHP vs React SPA
    • - Traditional PHP applications require full page reloads for every user action
    • - React Single Page Applications (SPA) render UI dynamically without refreshing, providing faster user experience
  • •
    Data Sync: HTTP Polling vs WebSocket Listeners
    • - Periodic HTTP polling generates high server load and network traffic
    • - Cloud Firestore provides real-time snapshot listeners that push updates instantly when database changes occur
  • •
    Fulfillment: Warehouse Inventory vs API Dropshipping
    • - Physical stock requires high capital investment and warehouse management
    • - Direct Open API integration automates catalog import and customer order fulfillment directly through suppliers

Methodology

System Architecture & Technology Stack

  • •
    Frontend Technologies: React 18 + Vite 6 with React Router v7 for client routing, Context API for state (Auth, Cart, Toast), and Tailwind CSS for mobile responsiveness
  • •
    Database & Authentication: Google Cloud Firestore for live NoSQL document storage; Firebase Authentication for Email/Password and Google OAuth login
  • •
    External APIs: CJ Dropshipping Open API for product catalog search and automated fulfillment; EmailJS for sending customer HTML emails
  • •
    Hosting & Deployment: Firebase CDN Hosting with global SSL encryption and single-page application rewrite routing

Methodology

Database Structure & User Access Control

  • •
    Database Collections (Cloud Firestore):
    • - products: Title, price, discount, images, sizes, colors, stock status
    • - categories: Category name, URL slug, active state
    • - orders: Order items, shipping address, payment status, tracking number
    • - users: User UID, email address, display name, account role
    • - reviews: Star ratings, customer comments, approval status
    • - inquiries: Customer messages submitted via Contact page
  • •
    Role-Based Access Control (RBAC):
    • - Admin: Full access to /admin panel to manage catalog CRUD, process orders, and manage users
    • - Customer: Access to /profile, view past orders synced by email/UID, and leave reviews
    • - Guest: Browse catalog, add to cart, guest checkout, and track orders using order ID

Discussion

Technical Challenges & Solutions

  • •
    1. API CORS on Localhost: External supplier API blocked browser requests due to CORS headers. Solution: Configured a local Vite server proxy during development, and direct HTTPS endpoint on Firebase production.
  • •
    2. Supplier API Rate Limits (HTTP 429): Multiple fast API calls caused request throttling. Solution: Implemented a client-side request queue with a 1000ms delay between consecutive requests.
  • •
    3. Browser Ad-Blocker Interference: Some privacy extensions blocked default Firestore WebSocket streams. Solution: Configured long-polling fallback (experimentalForceLongPolling) in Firebase initialization.
